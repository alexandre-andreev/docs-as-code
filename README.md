# 📚 Docs as Code — трекер изучения

Персональный трекер прохождения учебного плана по технологии **Docs as Code** —
методологии написания документации в том же цикле, что и код: текст в Git,
автоматические проверки, деплой через CI/CD.

> Этот репозиторий сам по себе является демонстрацией принципов Docs as Code:
> документация хранится в Git, публикация автоматизирована через GitHub Actions,
> история изменений видна в коммитах.

## Возможности трекера

- 7 фаз обучения, 57 задач — от основ Git и Markdown до ИИ в контуре документации
- Отметка выполненных задач с сохранением прогресса
- Комментарии к каждой задаче (ссылки, заметки, результаты)
- Экспорт прогресса в JSON и Markdown
- Импорт прогресса из JSON (перенос между устройствами)
- Добавление задачи в Google Календарь или Google Tasks одним кликом
- **Проверка ответов через ИИ** — Groq, DeepSeek, OpenAI, Claude (локальный backend)
- Работает локально через FastAPI-сервер; на GitHub Pages — без ИИ-проверки

## Запуск с локальным backend (рекомендуется)

Backend раздаёт фронтенд и обеспечивает ИИ-проверку ответов.  
**API-ключи хранятся только в `.env` на вашей машине и никогда не попадают в браузер.**

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Создание `.env`

Скопируйте пример и заполните ключи:

```
ANTHROPIC_API_KEY=...   # console.anthropic.com
DEEPSEEK_API_KEY=...    # platform.deepseek.com
OPENAI_API_KEY=...      # platform.openai.com
GROQ_API_KEY=...        # console.groq.com  (бесплатный)
GOOGLE_CLIENT_ID=...    # console.cloud.google.com (для Google Tasks)
```

Модели без ключа автоматически помечаются неактивными в интерфейсе.

### 3. Запуск

```bash
python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

Затем откройте `http://localhost:8000`.

На Windows — двойной клик по `docs as code.bat` на рабочем столе.

## Запуск без backend (только статика)

Для корректной работы из нескольких файлов нужен локальный HTTP-сервер
(браузеры блокируют загрузку скриптов через `file://` протокол).  
ИИ-проверка в этом режиме недоступна.

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .

# VS Code: расширение Live Server (Alt+L Alt+O)
```

Затем откройте `http://localhost:8000`.

## Деплой на GitHub Pages

Деплой настроен через GitHub Actions (`.github/workflows/deploy.yml`).
При каждом `push` в ветку `main` сайт автоматически публикуется на GitHub Pages.

**Первоначальная настройка:**

1. Создайте репозиторий на GitHub
2. Перейдите в **Settings → Pages → Source** и выберите **GitHub Actions**
3. Сделайте `push` в `main` — Actions запустится автоматически

После деплоя трекер будет доступен по адресу:
`https://<username>.github.io/<repo-name>/`

## Проверка знаний и ИИ-ревью (вариант A)

Для задач с вопросами рядом с иконками «Комментарий» и «Календарь» появляется значок **?**.
Клик раскрывает блок вопросов (3 на задачу, от базового к продвинутому).

**Цикл работы с вопросом:**

1. Прочитайте вопрос и напишите ответ в поле «Ваш ответ» своими словами.
2. Нажмите **📋 Проверить через ИИ** — готовый промпт скопируется в буфер обмена.
3. Откройте [Claude.ai](https://claude.ai) или ChatGPT и вставьте промпт.
4. Скопируйте оценку от ИИ и вставьте её в поле «Оценка ИИ» — она сохранится.
5. Нажмите **Эталонный ответ** — сравните со своим и с оценкой ИИ.

**Загрузка вопросов:**

- При старте приложение автоматически загружает `questions.json` из корня репозитория.
- Кнопка **📦 Вопросы** позволяет добавить файл вопросов для новых фаз прямо в браузере —
  старые ответы и оценки при этом сохраняются.

**Формат файла вопросов** описан в `Questions/questions-template.json`.
Генерируйте вопросы для новых фаз через Claude или ChatGPT по шаблону из этого файла,
затем добавляйте в `questions.json`.

> **Планируется в следующих версиях:**
> - Вариант B: прямой вызов Claude API (нужен API-ключ, настроенный в трекере)
> - Вариант C: бэкенд-прокси (для командного использования без раскрытия ключа)

## Перенос прогресса между устройствами

Прогресс хранится в браузере (localStorage). Для переноса:

1. Нажмите **📥 JSON** → **💾 Скачать** — сохраните файл прогресса
2. На другом устройстве нажмите **📂 Импорт** и выберите скачанный файл
